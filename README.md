# Honse Daughters
A work-in-progress server emulator for the global version of a horse racing game.

## Implemented Features
* CDN more or less working; unique test done was buggy but it still worked until the end
* Login and registration working
* Gacha working
* Presents more or less working (not all types of presents supported, only carats)
